# Paytm Autopilot — Setup on Another Laptop

Follow these quick steps to get Paytm Autopilot up and running on your other laptop:

## Prerequisites
- **Node.js**: Version 18.18+ or 20+ installed ([nodejs.org](https://nodejs.org/))
- **Terminal**: PowerShell, Bash, or Command Prompt

---

## 1. Extract the Zip
Extract `paytm-ai-project.zip` to your desired folder (e.g. `C:\Projects\paytm-ai` or `D:\paytm-ai`).

---

## 2. Open Terminal in the Project Folder
```bash
cd /path/to/extracted/paytm-ai
```

---

## 3. Install Dependencies
```bash
npm install
```
*(Note: If on Windows PowerShell and you encounter script execution restrictions, you can run `npm.cmd install` or run in Command Prompt).*

---

## 4. Run the Development Server
```bash
npm run dev
```

---

## 5. Open in Browser
Once started, visit:
👉 **http://localhost:3000/dashboard**

---

## Available Commands
- `npm run dev` — Start local development server (with Turbopack)
- `npm run build` — Build production bundle and verify TypeScript types
- `npm run start` — Run production server
- `npm run lint` — Run ESLint code quality checks
